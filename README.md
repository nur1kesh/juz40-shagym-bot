# Шағым боты (JUZ40 сервис)

## Процесс
1. **Тех/Ішкі сату** → «БІЛІМ + СЕРВИС 26-27» ішіндегі *Smart / Junior қызметкер хейт* topic-ке шағым жазады.
2. **Сыртқы сату** → «САТУ + СЕРВИС» ішіндегі *ҚЫЗМЕТКЕРГЕ ХЕЙТ* topic-ке жазады. Бот OpenAI арқылы SMART/JUNIOR екенін анықтап,
   тиісті topic-ке көшіреді (анықталмаса — SMART/JUNIOR түймелері шығады). Шешім шыққанда сыртқы сатуға да жауап қайтарылады.
3. Бот OpenAI-мен шағымды талдайды (оқушы, пән, ағын, қызметкер, мәселе атауы, сипаттама) → **roster.py** бойынша
   жауапты **координатор + супервайзерді** белгілейді, мерзім = 24 сағат.
4. Шешілмесе **әр сағат сайын** еске салады (жауаптыларды тегтеп). 24 сағаттан кейін «МЕРЗІМ ӨТТІ».
5. Координатор шағымға **reply** етіп шешім шаблонын жібереді (`/shesim`, немесе еске салудағы «📝 Шешім шаблоны» түймесі). Бот 5 өрісті тексереді (мәндер тізімнен), шешімнің нақтылығын OpenAI-мен тексереді. Дұрыс болса шағым жабылады; «Білім бөлімінің жауабы», «негізделген», «риза», «курста қалды» бағандары Excel-ге автоматты түседі.
6. `/export` → Excel (ТЕХ МЕНЕДЖЕР / ІШКІ САТУ / СЫРТҚЫ САТУ парақтары, бағандары түпнұсқамен бірдей).

**Жұмыс уақыты:** бот тек Дс–Сб 11:00–21:00 (Asia/Almaty) жазады. Жексенбі немесе түнде келген шағымдар кезекке тұрады,
11:00-де өңделеді. Тек `/командаларға` жауап уақытқа тәуелсіз.

## Іске қосу
1. @BotFather: бот жасаңыз, **Group Privacy → Disable** (бот барлық хабарламаны көруі керек).
2. Ботты екі топқа да **админ** етіп қосыңыз (хабарлама жазу, topic-терге қолжетімділік).
3. `copy .env.example .env` → `BOT_TOKEN`, `OPENAI_API_KEY` толтырыңыз.
4. ```
   pip install -r requirements.txt
   python -m bot.main
   ```
5. Әр topic ішінде админ ретінде команда жазыңыз:
   - БІЛІМ+СЕРВИС → *Smart қызметкер хейт*: `/bind smart`
   - БІЛІМ+СЕРВИС → *Junior қызметкер хейт*: `/bind junior`
   - САТУ+СЕРВИС → *ҚЫЗМЕТКЕРГЕ ХЕЙТ*: `/bind external`
6. Тексеру: `/bindings`, `/open`.

## Командалар
`/shablon [pin]`, `/shesim`, `/bind`, `/bindings`, `/open`, `/close ID`, `/export [YYYY-MM] [all]`, `/setrole tech|internal` (reply арқылы).

## Файлдар
- `bot/roster.py` — супервайзер/координатор тізімі (өзгерту үшін осы файлды өңдеңіз)
- `bot/ai.py` — OpenAI промпттары; `bot/service.py` — логика, еске салу; `bot/exporter.py` — Excel

## Шектеулер / нені білу керек
- Username-сіз адамдар (Мерей Мирида, Асем, т.б.) бот олар топта жазғаннан кейін ғана id арқылы тегталады.
- Телефон мен почта Excel-ге түспейді (бағаны жоқ), тек базада сақталады.
- Деректер `data/bot.db` (SQLite) ішінде. Ботты 24/7 қосулы тұратын серверге (VPS) қою керек.

## Railway
1. GitHub-қа жүктеп, Railway-де *New Project → Deploy from repo*. `Procfile` worker-ді іске қосады (web порт керек емес).
2. *Variables*: `BOT_TOKEN`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `TIMEZONE=Asia/Almaty`, `DB_PATH=/data/bot.db`.
3. **Volume** жасап `/data`-ға mount етіңіз, әйтпесе әр деплойда база өшеді.
4. Сенімсіз жауап: OpenAI сенімділігі < 0.7 болса, бот админдерді тегтеп «Жабу / Әлі жоқ» түймелерін көрсетеді.

## Тесттер
```
pip install pytest
python -m pytest tests -q
```
`tests/test_scenarios.py` — жалған Telegram және басқарылатын сағатпен бизнес-логика сценарийлері (жұмыс уақыты, SLA, еске салу, шаблон тексеру, сыртқы сату, қателер).
Мерзім (24 сағат) жауапты адамдарға **хабарланған сәттен** басталады (түнде/жексенбіде келген шағым дүйсенбіде бірден «мерзімі өтті» болмайды).
